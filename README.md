# pruneraft

Prune digests and raft fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/pruneraft/

## Install / run

```bash
git clone https://github.com/theworker02/pruneraft.git
cd pruneraft
node src/cli.js
node --test
```
